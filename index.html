How it works

From power-on
to play in a few steps.

Dusk is a live operating system image with a TV-style interface on top. It runs from the ISO instead of silently changing the computer’s existing operating system.

Boot Dusk

Start a compatible 64-bit PC from the Dusk ISO. Dusk logs into its live session and opens the full-screen home screen.

Choose with a remote or keyboard

Move around with the arrow keys, press Enter to select, and use Esc to go back. A TV remote that sends keyboard controls can work too.

Open a web app

App tiles are shortcuts to streaming and media websites in Chromium. They are not native apps, and some services need an account or subscription.

Before you boot

Good to know.

A few details about what a live ISO does—and what it doesn’t do.

Will Dusk replace or erase my current operating system?

Dusk is configured as a live system. Booting the ISO runs Dusk from the boot media and does not automatically install it onto your computer. When testing, carefully select the ISO as the boot device and do not choose an installer or disk operation unless you intend to.

Are the Store items full native apps?

No. They are website shortcuts that open in Chromium. Internet access is required, and each service controls its own sign-in, subscription, device support, and availability.

Will the ISO download install an update?

No. The update checker only downloads an ISO. To use it, boot from that ISO yourself. Back up anything important before changing boot settings.

Can my settings stay between live boots?

Yes, using the documented VirtualBox setup with a separate writable persistence disk. Keep that disk attached when starting Dusk. The disk is for Dusk settings and browser data; do not select a disk that contains files you need.
